# CSE 325 - Work with Files and Directories

This project was created for the Microsoft Learn module
"Work with files and directories in a .NET app."

## Features

The application demonstrates:

- Working with directories
- Finding files
- Working with file paths
- Creating files
- Reading files
- Writing files
- Processing data from files

## Additional Assignment Requirement

I added a sales summary report function.

The function:

1. Reads the sales files.
2. Calculates the total sales for each file.
3. Calculates the total sales across all files.
4. Builds a formatted report using StringBuilder.
5. Writes the report to a file.

The generated report is:
