# CSE 325 - ASP.NET Core Pizza Web API

This project was created for the Microsoft Learn module
"Create a web API with ASP.NET Core controllers."

## Features

The API supports CRUD operations:

- GET all pizzas
- GET a pizza by ID
- POST a new pizza
- PUT/update a pizza
- DELETE a pizza
